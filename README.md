# CredLink

> Turning financial behaviour into financial opportunity.

CredLink is a hackathon/demo Progressive Web App [installable web application] that turns verified informal financial activity, starting with susu participation, into a transparent financial behavior profile consumers can share with participating lenders.

CredLink is not a lender. It verifies permitted alternative financial information, explains financial behavior, estimates supportable loan options, and lets the customer share selected information with a lender. The financial institution makes the final decision.

```text
Identity
↓
Financial activity
↓
Verification
↓
Financial profile
↓
CredLink Score
↓
Loan guidance
↓
Customer consent
↓
Lender review
↓
Lender decision
```
